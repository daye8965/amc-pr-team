# 홍보팀 업무 대시보드

서울아산병원 홍보팀 업무를 구글 시트 「언론유닛 업무 공유」에서 받아 한 화면에서 보는 대시보드입니다.

**공개 주소: https://daye8965.github.io/amc-pr-team/**

| 탭 | 내용 |
|---|---|
| 📊 전체 현황 | 전체 업무 건수, 구분별 비중, 연도별 추이, 연동된 시트 탭 목록 |
| ⚖️ 업무량 분석 | 담당자별 업무량, 담당자 × 업무 구분 교차표 |
| 📋 업무 목록 | 전체 업무 검색 · 구분/연도/담당 필터 |
| 🎬 SNS 콘텐츠 | 유튜브 제작 건수, 분류 비중, 조회수 상위 |
| 💰 광고·협찬 | 연도별·언론사별 집행 금액, 집행 내역 |
| 🗓️ 도움말자료 | 연도별 기획 캘린더 |
| 📰 언론 보도 | 수집된 서울아산병원 기사 검색·통계, 원문 링크 |
| 📚 참조 자료 | 암병원 교수, 인터뷰 후보, 명의 출연진 등 |

## 설정

데이터는 저장소에 없고 Google Apps Script 웹 앱에서 받아옵니다.

1. https://script.google.com 에서 새 프로젝트를 만듭니다
2. [apps-script/Code.gs](apps-script/Code.gs) 내용을 붙여넣습니다
3. `testFeed` 를 실행해 실행 로그에서 탭별 건수를 확인합니다
4. `배포 > 새 배포 > 웹 앱` (실행: 나 / 액세스: 링크가 있는 모든 사용자)
5. 나온 `/exec` 주소를 `index.html` 의 `FEED_URL` 에 넣습니다

이후 코드를 고쳤을 때는 `배포 > 배포 관리 > 연필 > 새 버전`으로 재배포해야 주소가 유지됩니다.

## 언론 보도 데이터 갱신

```bash
python scripts/build_news.py
```

`hospital-news-dashboard/docs/news.csv` 에서 서울아산병원 기사만 추려 `data/articles.json` 을 만듭니다.
새 기사가 쌓이면 다시 돌리고 커밋하세요.

## 개인정보

공개 페이지이므로 기자·오피니언 연락처 탭은 연동하지 않습니다.
참조 탭에서도 전화번호·이메일 열은 Apps Script 단계에서 제외합니다.

## 로컬 확인

```bash
python -m http.server 8799
```

`http://localhost:8799/` 로 접속합니다.
