🔒 표시한 두 탭은 비밀번호를 넣어야 보입니다. 광고 금액은 **공개 피드에 실리지 않고**, 비밀번호가 맞을 때만 따로 받아옵니다.

수치는 대시보드가 아니라 **구글 시트에서 고칩니다.** 사이드바 아래 `구글 시트 열기` 버튼으로 바로 갈 수 있습니다.
예외는 보도자료 **게재일** 하나로, 배포 목록의 `날짜 수정` 버튼으로 비밀번호를 넣고 시트에 바로 쓸 수 있습니다.

## 설정

데이터는 저장소에 없고 Google Apps Script 웹 앱에서 받아옵니다.

1. https://script.google.com 에서 새 프로젝트를 만듭니다
2. [apps-script/Code.gs](apps-script/Code.gs) 내용을 **전부 복사해** 편집기에 붙여넣고 저장합니다
3. `testFeed` 를 실행하고 **권한을 승인**합니다 — 시트 읽기 외에 외부 접속(공휴일 달력·뉴스룸) 권한이 필요합니다.
   실행 로그에 탭별 건수와 `공휴일 201일`, `뉴스룸 보도자료 400건` 이 찍히면 정상입니다
4. **⚙ 프로젝트 설정 → 스크립트 속성**에 비밀번호 두 개를 넣습니다
   - `VIEW_PW` — 광고 탭을 열 때 쓰는 보기 비번
   - `EDIT_PW` — 보도자료 날짜를 고칠 때 쓰는 쓰기 비번 (12자 이상 권장)
5. `배포 > 새 배포 > 웹 앱` (실행: 나 / 액세스: 링크가 있는 모든 사용자)
6. 나온 `/exec` 주소를 `index.html` 의 `FEED_URL` 에 넣습니다

이후 코드를 고쳤을 때는 `배포 > 배포 관리 > 연필 > 버전을 새 버전으로 > 배포` 로 올려야 주소가 유지됩니다.
**저장을 먼저 하세요.** 저장 전에 배포하면 버전 번호만 올라가고 코드는 그대로입니다.

반영됐는지는 **사이드바 맨 아래 한 줄**로 확인합니다 — `시트 8탭 · 스크립트 2026-11-24d`.
코드를 고칠 때 `SCRIPT_VERSION` 을 올려두면 이 숫자로 바로 알 수 있습니다.

## 언론 보도 데이터 갱신

```bash
python scripts/build_news.py
```

`hospital-news-dashboard/docs/news.csv` 에서 서울아산병원 기사만 추려 `data/articles.json` 을 만듭니다.
광고·협찬의 기사 링크에 씁니다. 새 기사가 쌓이면 다시 돌리고 커밋하세요.

## 개인정보

공개 페이지이므로 기자·오피니언 연락처 탭은 연동하지 않습니다.
참조 탭에서도 전화번호·이메일 열은 Apps Script 단계에서 제외합니다.

## 로컬 확인

```bash
python -m http.server 8800
```

`http://localhost:8800/` 로 접속합니다. 시트 접근이 돼야 데이터가 뜹니다.
